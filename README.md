# ChangeShift

ChangeShift é um aplicativo iOS simples e interativo desenvolvido com Swift e UIKit, que permite ao usuário alternar entre os turnos **diurno** e **noturno**, personalizando a saudação exibida com seu nome e visualizando imagens temáticas para cada turno.

---

## ✨ Funcionalidades

- Alternância entre turnos: **Good Morning** / **Good Night**
- Interface dinâmica: cores, imagens e textos mudam conforme o turno
- Personalização da saudação com o nome do usuário
- Navegação para tela de detalhes com imagem complementar do turno

---

## 🧪 Tecnologias Utilizadas

- Swift
- UIKit
- Storyboard
- Auto Layout
- Enum (`Shift`)
- Navegação com `segue` e `prepare(for:)`
